# Реальные наборы из Issue #1

Базовые восемь файлов двух сезонных наборов импортированы **без изменения содержимого** из [комментария к #1](https://github.com/DAIRN-Universe/steppe-jukebox/issues/1#issuecomment-6873947119). Из блока Python прочитан только литерал `files` через `ast.literal_eval`; сам скрипт комментария не исполнялся. Контрольные суммы восьми исходных файлов и ссылка на комментарий записаны в [provenance.json](provenance.json).

Координаты, даты, ID, классы и пропуски сохранены. Данные представляют классы опубликованных визуализаций NASA, а не исходные численные измерения NDVI. Классы NOAA‑20 и EIC получены по разным цветовым легендам; сравнивать сезоны следует **внутри одного набора**, не смешивая два источника.

| Набор | Источник и даты | Ячеек | Пропусков весной / летом | Длительность каждого сезона |
| --- | --- | ---: | ---: | ---: |
| `noaa20-kostanay` | NASA GIBS NOAA‑20 / VIIRS, 2026-04-15 / 2026-07-16 | 48 | 1 / 0 | 24 с |
| `eic-kostanay` | NASA EIC / SVS 5544, 2025-04-15 / 2025-07-15 | 137 | 0 / 46 | 68,5 с |

По описанию автора комментария оба профиля проходят Каменное озеро → Наурзум → Аккум. Точные последовательности координат заданы в `route.csv`. NOAA‑20 использует отображённые интервалы скользящего 8-дневного композита, EIC — пять цветовых классов по градиенту SVS 5544. Точные ссылки источников и даты взяты из переданных `metadata.json`.

## Локальный запуск

Из корня репозитория, с установленными зависимостями preview:

```bash
STEPPE_DATA_DIR="$PWD/data/real-test/noaa20-kostanay" .venv/bin/python -m streamlit run app.py
```

Второй набор на отдельном порту:

```bash
STEPPE_DATA_DIR="$PWD/data/real-test/eic-kostanay" .venv/bin/python -m streamlit run app.py --server.port 8502
```

Основной набор для короткой технической демонстрации и набор по умолчанию в v0.2.0 — NOAA‑20, как предложено в комментарии #1. EIC сохраняет исходные даты кандидатов задачи #1. Другой набор выбирается через `STEPPE_DATA_DIR`; синтетический остаётся в `data/synthetic`. Звуковая шкала и контракты сезонных CSV не менялись.

## Путешествие #11

В папку `noaa20-kostanay` добавлен отдельный `journey.csv` из [Issue #11](https://github.com/DAIRN-Universe/steppe-jukebox/issues/11), без изменения классов и дат. Его 48 ID совпадают с маршрутом #1. Даты идут от 2026-04-15 до 2026-11-13, KST-018 — 2026-07-01. Контрольные суммы и источник записаны в `journey_provenance.json`; метаданные источника и ориентиры — в `journey_metadata.json`. Это дополнение не меняет исходные восемь файлов #1.

Распределение путешествия: класс 1 — 3 шага, 2 — 27, 3 — 15, 4 — 3, 5 — 0; пропусков в исходном ряду нет. В сравнении с фиксированным весенним срезом 2026-04-15 сопоставимы 47 точек, 34 имеют другой класс: 16 выше, 18 ниже, 13 без изменения. Это сравнение таблиц, а не результат прослушивания и не временной тренд: дата и место меняются одновременно.

В интерфейсе выбрать «Режим → Путешествие во времени». Шкала, громкость синтеза и шаг 0,5 с общие с фиксированными сезонами; дорожка занимает 24 с. Пустой класс поддерживается и проверяется на отдельной тестовой копии. Экспорт NOAA‑20 дополнительно создаёт `journey.wav` и CSV таймингов с датами.

## Сравнение переданных последовательностей

| Набор | Ячеек с данными в обоих сезонах | Различаются | Класс летом выше / ниже / тот же |
| --- | ---: | ---: | ---: |
| NOAA‑20 | 47 | 36 | 19 / 17 / 11 |
| EIC | 91 | 72 | 72 / 0 / 19 |

Пропуски исключены только из подсчёта сопоставимых пар. В маршруте и звуковой дорожке они остаются на своих местах и занимают полный интервал 0,5 с.

Распределение классов:

| Набор / сезон | 1 | 2 | 3 | 4 | 5 | Нет данных |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| NOAA‑20 / весна | 0 | 28 | 19 | 0 | 0 | 1 |
| NOAA‑20 / лето | 0 | 26 | 14 | 7 | 1 | 0 |
| EIC / весна | 1 | 136 | 0 | 0 | 0 | 0 |
| EIC / лето | 0 | 19 | 5 | 63 | 4 | 46 |

**Решение по импортированным таблицам:** различающихся ячеек достаточно для технического сравнения; расширять маршрут или интерполировать значения для создания контраста не требуется. NOAA‑20 даёт короткое сравнение с одним пропуском, причём изменения классов направлены в обе стороны. EIC даёт заметно отличающуюся партитуру, но 46 летних пропусков означают 23 секунды тишины. Эти пропуски не интерпретируются как низкий NDVI или изменение растительности. Ожидаемые ноты выводятся из общей шкалы C4–D4–E4–G4–A4; это вывод по таблицам, не результат субъективного прослушивания.

## Проверка и экспорт

```bash
.venv/bin/python -m pytest -q tests/test_real_data.py
.venv/bin/python -m playwright install chromium
.venv/bin/python -m pytest -m browser -q tests/test_browser.py -k issue_1_real
.venv/bin/python -m steppe_jukebox.export --data-dir data/real-test/noaa20-kostanay --output-dir artifacts/real-test/noaa20-kostanay
.venv/bin/python -m steppe_jukebox.export --data-dir data/real-test/eic-kostanay --output-dir artifacts/real-test/eic-kostanay
```

Проверяются контрольные суммы импорта, контракт/порядок ID, даты, число пропусков, количество сопоставимых/различающихся пар, WAV и границы отсчётов. Браузерные проверки проходят на обоих наборах: настоящий старт с клавиатуры, пауза, отсутствие автозапуска, остановка при смене сезона, подсветка пропуска, сохранение позиции при смене языка и завершение дорожки. Для длинных маршрутов маркеры автоматически уменьшаются; активная ячейка увеличивается, получает номер и рисуется поверх соседних. Таблица сохраняет все ID и интервалы.

WAV и таблицы таймингов воспроизводимо создаются в игнорируемой папке `artifacts/`; их не требуется хранить в Git. Исходные CSV и метаданные работают с неизменённым загрузчиком preview.

## Граница этой реализации

Здесь подключены и проверены готовые таблицы, приложенные к #1. Повторное извлечение классов из PNG и независимая проверка их соответствия исходной цветовой легенде в этот шаг не входили. Исходные кадры доступны по ссылкам в метаданных; локальные вырезки и спутниковая подложка в интерфейсе не добавлены. Профиль и названия ориентиров взяты из комментария, их географическая точность здесь независимо не подтверждалась.

Поэтому полную научную/визуальную проверку #1 нельзя подменять успешным импортом CSV. Пользователь подтвердил ручной сценарий NOAA‑20 Костанайской области перед выпуском v0.2.0, включая сравнение фиксированного среза и путешествия. Отдельное прослушивание EIC, сверка с исходными изображениями и проверка настоящим экранным диктором не подтверждены. Результат и границы приёмки описаны в [отчёте выпуска](../../docs/RELEASE_0.2.0.md). Прежний `v0.1.0-preview.1` сохранён.
