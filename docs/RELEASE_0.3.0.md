# Выпуск v0.3.0

Выпуск двух областей и нового интерфейса от 2026-11-14. Реализует #13 и Акмолинскую часть #11 поверх `v0.2.0`. Пользователь подтвердил ручную проверку приложения и затем разрешил фиксацию изменений и выпуск новой версии. Дополнительные ботанические данные и источники оставлены следующим версиям.

## Что изменилось

- Выбор Костанайской и Акмолинской областей с отдельными картами, CSV, датами и дорожками.
- Компоновка прототипа перенесена в существующий компонент: «Слушать степь», «Растения и места», «Как это работает»; мобильные экраны и интерфейс ru/kk/en.
- Координатные оси поверх географических контуров OpenStreetMap с атрибуцией ODbL. Акмолинская область сохраняет пять внутренних вырезов. Геометрия и маршрут проецируются из WGS 84; экранные координаты SVG не принимаются за географические.
- Смена области, сезона и режима останавливает прежнюю дорожку и сбрасывает позицию/подсветку без автозапуска. Выбранные режим и сезон сохраняются при смене области. Язык и раздел можно менять без прерывания звука или пользовательской паузы.
- Кнопка «С начала», клавиатурная навигация, синхронные маркер, дата и строка таблицы на одном аудиочасе.
- Полевой контекст отделён от спутниковых наблюдений. Костанайские описания сохраняют собственные даты; на Акмолинскую область они не переносятся.

| Акмолинская | 56 | 28 с | 2026-04-15 / 2026-07-16 | 2026-04-15 … 2026-11-13 |

Шкала C4–D4–E4–G4–A4, 120 BPM, шаг 0,5 с и громкость синтеза сохранены. В Акмолинском путешествии AKM-027 / 2026-07-24 остаётся тишиной в 13,0–13,5 с, дата и маркер проходят этот интервал. Пользовательская пауза останавливает все позиции. Фиксированная весна Акмолы содержит паузы AKM-005 и AKM-027, лето — AKM-027.

## Запуск

Python 3.11+, из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Открыть `http://localhost:8501`. Костанайская область выбрана первой; вторую область выбрать в поле «Область». `STEPPE_DATA_DIR` сохраняет возможность открыть отдельный набор. CSV-контракт не изменён: замена наблюдений не требует правок звукового кода или интерфейса.

## Следующие версии и границы проверки

Дополнительная ботаника и источники отложены по решению пользователя. Экранный диктор, независимая сверка классов с исходными изображениями и школьная приёмка остаются отдельной работой. Новых спутниковых рядов, осеннего/зимнего режима и аккомпанемента нет.

Классы отражают интервалы отображаемой легенды скользящих 8-дневных композитов, а не исходный числовой NDVI с научной QA. В путешествии меняются место и дата; оно не устанавливает временной тренд. Точки маршрута не обозначают спутниковые пиксели или ячейки одинаковой площади.
