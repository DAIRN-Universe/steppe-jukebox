# Steppe Jukebox 1.0.0 — релиз хакатона

Стабильный выпуск для NASA Space Apps Challenge: The Earth Information
Jukebox. Пользователь подтвердил итоговую сборку и разрешил её публикацию
как **1.0.0**. Она заменяет непубликовавшийся кандидат 0.6.0; поведение
принятого приложения сохранено, номер версии в интерфейсе обновлён.

[GitHub Release v1.0.0](https://github.com/DAIRN-Universe/steppe-jukebox/releases/tag/v1.0.0)
содержит исходный код для запуска Python/Streamlit. Публикация GitHub
Release сама по себе не создаёт публичный экземпляр Streamlit и не
отправляет заявку на конкурс.

## Возможности

- Костанайская и Акмолинская области, отдельные контуры и готовые маршруты.
  Костанай: Каменное озеро → Наурзум → Аккум, 48 шагов / 24 с; Акмола:
  четыре ориентира, 56 шагов / 28 с.
- NASA GIBS / NOAA-20 и NASA EIC / Suomi NPP, точная дата, явная загрузка,
  диагностика ошибок и раздельный кэш. Другая дата или источник автоматически
  не подставляются.
- От одной до пяти опорных точек на сетке, список координат, удаление и
  сброс. Сервер проверяет лимит, границы области и внутренние вырезы.
  Водная маска не используется и не ограничивает выбор.
- Масштаб 100–800% кнопками, колесом и двумя пальцами; перетаскивание
  увеличенной карты и возврат к общему виду. Жесты не добавляют лишних точек.
- Панель точек свёрнута под «Загрузить маршрут». Предстоящий путь скрыт;
  аудиочасы определяют текущую ячейку, пройденный след, сведения о точке
  и положение шкалы. Пауза, перемотка, шаг назад/вперёд и перезапуск.
- Один плеер, пять нот C4–D4–E4–G4–A4, 120 BPM, по 0,5 с на шаг.
  Нет данных — полный интервал тишины. Классы соответствуют цветам
  визуализации, а не точным численным измерениям NDVI.
- Две вкладки: «Слушать степь» и «Как это работает». Научная вкладка
  скрыта, её материалы сохранены в коде. Смена вкладки и языка сохраняет
  звук и пользовательскую паузу.
- Компактный список kk/en/ru: основной язык браузера при открытии,
  английский при неподдерживаемом языке. Логотип открывает сайт хакатона.
  Управление с клавиатуры, видимый фокус, мобильная компоновка.
- Сохранённые сезонные CSV и путешествия доступны отдельно через
  `STEPPE_SAVED_REGIONS=1`; исходные данные и LICENSE не изменены.

## Воспроизводимый запуск

Python 3.11 или новее:

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/DAIRN-Universe/steppe-jukebox.git
cd steppe-jukebox
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Открыть http://localhost:8501, выбрать область, источник и дату, нажать
«Загрузить маршрут», затем «Запустить». Для первой проверки: GIBS —
10.06.2026, EIC — 20.04.2026. Пустой кэш требует сети; первый глобальный
кадр EIC на проверенном соединении загружался около двух минут. Повтор
тех же входных данных доступен из подготовленного кэша без сети.

Подробности запуска, CSV и экспорта: [LOCAL_DEMO.md](LOCAL_DEMO.md).

## Границы проверки

Полный архивный браузерный набор не объявляется зелёным. Восемь прежних
сбоев воспроизведены на неизменённом `58eb330` до маршрутного MVP:
семь старых ожиданий видимости после смены интерфейса и краевая подпись
оси в архивной одноточечной фикстуре. История и предыдущие прогоны:
[RELEASE_0.6.0.md](RELEASE_0.6.0.md).

Отдельными задачами остаются независимая сверка классов с исходными
кадрами, настоящее прослушивание сезонных различий, экранный диктор,
физическое мобильное устройство, школьная приёмка, новые сезоны и
конкурсная отправка. Релиз не подменяет эти результаты. Годовая водная
маска и научная QA не входят в принятый MVP. Скачанные кадры и тайлы
в архив исходников и ресурсы GitHub Release не добавляются.
