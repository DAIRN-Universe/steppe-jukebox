Сводка выпуска находится в [RELEASE_0.3.0.md](RELEASE_0.3.0.md). README уточнён для двух областей, MANIFESTO и LICENSE сохранены. ## Исходные материалы

Использован `Steppe-Jukebox-Preview-Akmola.html` из локальной папки NASA 2026. Его SHA-256 совпал с записью `prototype-route.json` в NASA fixture: `e98b06912c697cf364a8913cad04ac971779351d4d9ec8554c6e9491d86f6947`. Из прототипа перенесены компоновка, навигация, мобильное представление и полевой контекст. Его JS-проигрыватель, таймер, демонстрационные классы, анонимные квадраты и вручную записанные ноты не использованы.

Все три архива получены из [комментария #13](https://github.com/DAIRN-Universe/steppe-jukebox/issues/13#issuecomment-6876016651), распакованы и проверены:

| Материал | Что использовано |
| --- | --- |
| `steppe-region-maps-svg.zip` | `MAP-SOURCES.md`, оригинальные SVG как справочные материалы, новый Акмолинский GeoJSON |
| `steppe-jukebox-akmola-nasa-fixture.zip` | Фиксированные сезонные CSV, метаданные, аудит и происхождение тайлов, привязка маршрута |
| `steppe-jukebox-akmola-journey-2026-for-idea.zip` | Маршрут, путешествие, метаданные, аудит, происхождение, легенда и контрольные тайминги; WAV использован для побайтного сравнения |

URL и SHA-256 архивов записаны в `ISSUE_13_MATERIALS.json`. В `data/real-test/noaa20-akmola/journey_provenance.json` сохранены контрольные суммы импортированных файлов и контрольного WAV. Архивные CSV сохранены побайтно, включая CRLF. Значения и порядок Акмолинских `route.csv` / `journey.csv` совпали с #11; различались только окончания строк.

Костанайская географическая основа — исходный проектный GeoJSON OSM relation 1288730, подтверждённый `MAP-SOURCES.md`. Акмолинская — новый GeoJSON из архива, OSM relation 215743. Загрузчик понимает Polygon/MultiPolygon, Feature и FeatureCollection с одним объектом области. Маршрут и контур проецируются из WGS 84 одной функцией. Внутренние пять колец Акмолинского контура сохраняются как вырезы с правилом заливки `evenodd`. Координаты SVG не принимаются за долготу и широту. Атрибуция OSM/ODbL показана рядом с картой; ссылки на геометрию и лицензию доступны в карточке маршрута.

## Что работает

- Разделы «Слушать степь», «Растения и места», «Как это работает», адаптивная карта с плеером и боковыми карточками.
- Выбор Костанайской и Акмолинской областей через общий каталог `data/regions.json`. Наборы, геометрия, даты, подписи и звук переключаются вместе. Звуковая логика не зависит от названия области или числа шагов.
- Фиксированные срезы весны/лета и путешествие во времени для обеих областей. При смене области сохраняются выбранные режим и сезон; позиция и подсветка сбрасываются.
- Смена области, сезона или режима синхронно останавливает прежний трек, в том числе при незавершённом запуске, без автозапуска нового. «С начала» также сбрасывает позицию без автозапуска.
- Общий аудиочас управляет звуком, маркером, строкой таблицы, датой и положением на маршруте. Смена языка и раздела сохраняет воспроизведение или пользовательскую паузу.
- ru/kk/en, язык системы по умолчанию и сохранение ручного выбора. Клавиатура: Tab, Enter/Space на кнопках, стрелки в селекторах; стрелки/Home/End в навигации разделов.
- Координатные оси и деления, точные даты, ссылки на источники наблюдений, легенда классов/нот, состояние «нет данных → пауза».
- Костанайские полевые описания имеют собственные даты: Наурзум / 2010 и Каменное озеро / 2019–2022. Аккуму не приписаны виды других площадок. Для Акмолинской области показано отсутствие установленного локального ботанического описания; Костанайские карточки и исследования туда не переносятся.

Акмолинское путешествие из существующего синтезатора и экспортера побайтно совпало с `journey-reference.wav` из архива: SHA-256 `686700038c7d1aa03396635c7ec37b626c50423fb0fbe3539f920bd10e031d1a`. На AKM-027 сохраняется точный интервал тишины 13,0–13,5 с, дата и маркер движутся дальше по аудио. Пользовательская пауза фиксирует все три позиции.

## Локальный запуск и замена данных

```bash
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8503
```

По умолчанию доступны обе области. Костанайская выбрана первой. При замене наблюдений редактируются CSV и метаданные соответствующего каталога; интерфейс и звуковой код не меняются. Каталог областей указывает отдельные папки данных и географические основы. Контракт остаётся прежним: `route.csv` — `cell_id,lat,lon`; сезоны — `cell_id,ndvi_class`; путешествие — `cell_id,date,ndvi_class`. Порядок и ID проверяются строго; пропуски не заполняются.

`STEPPE_DATA_DIR` по-прежнему открывает отдельный набор, в том числе синтетический или EIC. Необязательный `journey_metadata.json` задаёт источник и ключи перевода ориентиров.

## Проверки

```bash
.venv/bin/python -m pytest -q
STEPPE_BROWSER_EXECUTABLE=/snap/chromium/current/usr/lib/chromium-browser/chrome \
  .venv/bin/python -m pytest -q -m 'browser or not browser'
.venv/bin/python -m steppe_jukebox.export \
  --data-dir data/real-test/noaa20-akmola --output-dir artifacts/issue13/noaa20-akmola
```

Без системного Chromium установить браузер через `python -m playwright install chromium` и убрать `STEPPE_BROWSER_EXECUTABLE`.

Проверки включают прежнюю регрессию; обе области; весь 24-секундный Костанайский и 28-секундный Акмолинский проход; каждый ID и дату по аудиочасам; порядок нот и полные интервалы тишины; пропуск AKM-027 и последующий шаг; пользовательскую паузу; переключение областей во время звука, на паузе и при незавершённом запуске; смену режимов и сезонов; отсутствие автозапуска; повтор; клавиатуру; независимые полевые описания; сохранение звука/паузы при смене языка и раздела. Географическая привязка и компоновка проверяются на ru/kk/en при ширинах 1440, 390 и 320 px. Итог полного прогона: **153 passed** — 95 проверок Python и 58 браузерных, 248,19 с. Браузер: Chromium 157; Python 3.12.3. JUnit-отчёт и итоговые скриншоты сохранены локально в `test-results/issue13-results.xml` и `test-results/ui13-final/` (не включаются в Git). После изменения размера окна тест читает заново отрисованный контур; подпись широты получила дополнительный отступ для экрана 320 px.

## Отдельная ручная приёмка

Пользователь подтвердил ручную проверку текущей локальной реализации: «я проверил всё работает». Ручная проверка приложения отмечена как пройденная. Подробные результаты по отдельным сценариям, субъективное сравнение звучания и проверка настоящим экранным диктором отдельно не переданы; дополнительные результаты не приписываются этому подтверждению.

Сценарий для повторной проверки: выбрать каждую область, сравнить весну/лето с путешествием при одной громкости, проверить пуск/паузу с клавиатуры, сменить область/режим/сезон во время звука и убедиться в остановке без автозапуска. В Акмолинском путешествии на AKM-027 / 24.07 должна быть тишина с продолжающимся движением даты и маркера; пользовательская пауза должна остановить движение. Повторить управление на узком экране и проверить сообщения ru/kk/en.

Классы — интервалы отображаемой легенды скользящих 8-дневных композитов, а не исходный числовой NDVI с научной QA. Даты проверены по предоставленным аудитам и происхождению; исходные тайлы повторно не загружались. Маршрут одновременно меняет место и дату и не устанавливает временной тренд. Точки не выданы за центры спутниковых пикселей или ячейки одинаковой площади. Новые спутниковые ряды, изменение темпа/нот, аккомпанемент и осенний/зимний режим в работу не входят.

Дополнительные данные по ботанике и источники по решению пользователя отложены до следующих версий. Они не входят в текущий объём #13. После ручной проверки пользователь отдельно разрешил фиксацию и выпуск новой версии.
