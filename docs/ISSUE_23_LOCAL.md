# Проверка issue #23

Контуры OSM, даты получения и условия указаны в [MAP-SOURCES.md](../data/maps/MAP-SOURCES.md). Именованные пункты обозначают ближайшую допустимую ячейку, а не точные координаты города. На 16.11.2026 живые загрузчики проверены для каждого готового маршрута: GIBS NOAA-20 — 2026-04-15, EIC Suomi NPP — 2026-04-20; оба завершили построение карты и дорожки со статусом `ready`. Легенды и классификация используются из существующих загрузчиков; записи с пустым значением в региональных файлах не являются наблюдениями. Проверка GIBS на 2026-04-20 для первых двух областей вернула `route_data_error`, дата не подменялась.
