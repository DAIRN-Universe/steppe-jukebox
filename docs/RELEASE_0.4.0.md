# Выпуск v0.4.0

15.11.2026, Asia/Qostanay. Первый выпуск, в котором карта и звук основного
плеера строятся из загружаемых данных NASA либо проверенного кэша загрузчика.
Реализована согласованная часть [#14](https://github.com/DAIRN-Universe/steppe-jukebox/issues/14)
поверх v0.3.0. Пользователь подтвердил работу приложения и разрешил сначала
объединить рабочую ветку с локальным `main`, затем опубликовать версию;
рабочая ветка не отправляется на удалённый репозиторий.

## Что вошло

- Один основной интерфейс и плеер: NASA GIBS / NOAA-20 по умолчанию,
  NASA EIC / Suomi NPP по выбору. Отдельный промежуточный экран NASA
  не включён в выпуск.
- Выбор области и точной даты, явная кнопка «Загрузить». EIC получает
  список дат из каталога SVS 5544, проверяет точный файл 8640×4320,
  использует собственную шкалу цвета и отдельное пространство кэша.
- Карта, инспектор, легенда, таблица и WAV используют выбранный источник
  и дату; в путешествии — дату текущего шага. Нет скрытой подмены
  сохранённым CSV, WAV, соседней датой или другим источником.
- Сетка всей области внутри контура OSM: пересекающие границы клетки
  исключены. Ключевые места отмечены «+» (три в Костанайской области,
  четыре в Акмолинской). Будущий путь скрыт; текущая клетка и пройденный
  след появляются по позиции звука. «С начала» очищает след.
- Прогрессивная загрузка GIBS с ограничением параллелизма, проверка
  фактической даты каждого тайла, диагностика и очистка кэша. Ошибки
  сети/даты/цвета отличаются от прозрачного пикселя и не выдаются за паузы.
- Дополнительные слои GIBS: вероятный снег по NDSI при отсутствующем NDVI,
  температура как отдельный признак и вода по маске NASA с указанием года.
  Наложения не перекрывают валидный NDVI и не меняют звуковую шкалу.

Сохранены две области: Костанай — 48 позиций / 24 с, Акмола — 56 / 28 с;
пять нот C4–D4–E4–G4–A4, 120 BPM, шаг 0,5 с. Источник, область, дата,
режим или слои меняются с немедленной остановкой звука и сбросом позиции,
без автозапуска. Смена языка или раздела сохраняет звук и пользовательскую
паузу. Доступны ru/kk/en, системный выбор языка, мобильное представление,
клавиатура и прежний ботанический контекст.

## Что подтверждено

Реальные GIBS и EIC проверены на одном Костанайском маршруте за
20.04.2026 и 10.06.2026: холодная загрузка, повтор из кэша, фактическая дата,
48 точек, WAV и интерфейс. У EIC дата подтверждается точным именем файла
в каталоге и каноническим URL без перенаправления; у GIBS — заголовком
`layer-time-actual`. Не следует считать эти типы подтверждения одинаковыми.

Восемь сочетаний двух областей, двух источников и двух дат готовы при
запрещённых HTTP-запросах: 0 сетевых запросов и 0 ошибок тайлов, 24/28 с
звука. Исходные кадры и метаданные подготовлены тем же загрузчиком;
срезов для скрытого резервного воспроизведения в выпуск не добавлено.

Одиночные холодные замеры от старта серверного задания до готовности
карты и WAV: GIBS **4,535–8,336 с** (15 запросов на дату), EIC
**104,978–125,000 с** (первый кадр плюс каталог — два запроса, второй
кадр — один). EIC скачивает глобальный PNG 13,2/15,8 МБ, затем вырезает
область. Актуальная проверка из кэша без сети: **0,988–1,695 с** по
восьми комбинациям. Это не время первого тайла в браузере и не обещание
скорости NASA. Подробные замеры первоначального экрана сохранены отдельно.

Перед выпуском пройдены **25 целевых автоматических проверок**: 11 загрузчика
и интеграции, шесть браузерных, четыре регрессионных для сохранённых данных,
четыре локализаций. После изменения пути повторён один существующий
браузерный сценарий областей/источников/дат/путешествия/офлайн-кэша.
На реальных кэшированных данных отдельно проверены «+», отсутствие будущего
пути, текущая и пройденные клетки, клавиатура, пауза, завершение, сброс,
смена источника во время звука, три языка и ширины 1440/390/320 px.

## Запуск

Python 3.11+, из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Открыть http://localhost:8501, выбрать область, источник и дату, нажать
«Загрузить», затем запустить звук кнопкой или Enter/Space. Для первого
сравнения выбрать 20.04.2026 или 10.06.2026. Пустой кэш требует сети;
повторное воспроизведение полностью подготовленных дат работает без сети.

Исходные PNG и проверенные метаданные хранятся вне Git в пользовательском
кэше (`~/.cache/steppe-jukebox/nasa-gibs` и `nasa-eic` на Linux). Раздел
«Проверка загрузки» содержит запросы, ошибки, обновление дат EIC и очистку.
Очистка кэша возвращает необходимость сетевой загрузки; исходные файлы
выпущенной v0.3.0 не изменяет.

Для прежнего двухобластного демо на сохранённых данных:

```bash
STEPPE_SAVED_REGIONS=1 python -m streamlit run app.py
```

Отдельный набор CSV выбирается через `STEPPE_DATA_DIR`. Это явные режимы,
а не автоматический резерв при сбое NASA. Контракты CSV и команды экспорта
остаются в [LOCAL_DEMO.md](LOCAL_DEMO.md).

## Границы выпуска и следующий этап #14

Оба источника показывают NDVI, но это разные продукты и шкалы визуализации.
EIC классифицируется по пяти участкам своей шкалы Low–High; численное NDVI
из цветного кадра не восстанавливается. Равные номера классов между EIC
и GIBS не означают равных численных значений. NOAA-20 — скользящий
8-дневный композит, а не наблюдение в момент проигрывания.

На момент проверки EIC-каталог заканчивался 13.06.2026. Путешествие,
требующее отсутствующих кадров, сообщает об ограничении и не создаёт звук.
Полное сетевое путешествие GIBS по всем реальным датам маршрута не
загружалось в этом прогоне; смена даты карты и последний шаг проверены
на контролируемых ответах. Это ограничение явно остаётся открытым.

Произвольный маршрут из координат, промежуточные точки, экспорт его CSV/WAV,
контрольные прогоны новых маршрутов, дальнейшая ботаника и проверка экранным
диктором не включены. #14 остаётся открытой для оставшихся этапов.

Ранее выпущенные CSV, карты и `sound.py` сохранены побайтно. README и
руководство запуска уточнены по необходимости. MANIFESTO, LICENSE и теги
прежних версий не менялись. Посторонний документ про Godot, промежуточный
экран, пользовательский кэш, WAV, скачанные тайлы и тестовые артефакты
в выпуск не входят.
