# Версия 0.6.0 — маршруты по точкам и масштаб карты

Пользователь подтвердил работу приложения («всё работает») и разрешил
слияние всех принятых изменений в `main`, обновление/закрытие выполненных
задач и подготовку версии 0.6.0 к публикации. Основа — v0.5.3.
GitHub Release подготавливается **черновиком**: публикация релиза и
отдельное развёртывание публичного Streamlit не выполняются этим шагом.

## Изменения

- Один экран «Одна дата», один плеер, GIBS/NOAA-20 и EIC/Suomi NPP.
- От одной до пяти опорных точек на существующей сетке области,
  последовательные клики/касания, список названий и координат, удаление,
  сброс к штатному маршруту. Лимит и принадлежность области проверяет
  сервер. Промежуточных шагов может быть больше пяти; повторные заходы
  сохраняются с отдельными ID, совпавшие стыки участков объединяются.
- Штатные маршруты сохранены: Костанай — **48 шагов / 24 с**, Акмола —
  **56 / 28 с**. На Костанайской карте три маркера: Каменное озеро →
  Наурзум → Аккум; на Акмолинской четыре прежних ориентира. Дублирующие
  знаки «+» убраны.
- Предварительный путь скрыт; видны маркеры. Проигрывание и перемотка
  показывают текущую ячейку и пройденный след. Перемотка назад скрывает
  будущий участок, перезапуск скрывает весь след до начала проигрывания.
- Панель «Точки маршрута» находится под «Загрузить маршрут», свёрнута
  по умолчанию и показывает счётчик в заголовке. Enter/Space раскрывают
  её; закрытие сохраняет точки, черновик, выбор на карте и аудиопозицию.
  Ошибки редактирования раскрывают сообщение.
- Масштаб 100–800% кнопками, колесом и двумя пальцами; перетаскивание
  увеличенной карты; «Вся карта». Жесты не ставят лишних точек, а оси,
  изображения, маркеры и подсветка используют одну проекцию.
- **Ограничение воды отменено пользователем. Водная маска не используется
  и не запрашивается.** Сохраняются границы области и внутренние вырезы,
  включая запрет диагонального среза их углов. Пропуск NDVI даёт паузу.
- Смена даты/источника сохраняет геометрию и масштаб, сбрасывает аудио
  и требует явной загрузки. Неудачный черновик не заменяет действующий
  маршрут; поздние ответы старых запросов отбрасываются.
- Сохранены 120 BPM, шаг 0,5 с, пять нот, проверенный кэш, ru/kk/en,
  клавиатура, компактная строка плеера и узкие экраны. Исторические
  CSV/WAV и режим путешествия доступны через `STEPPE_SAVED_REGIONS=1`.

## Уточнения шапки перед публикацией

- Логотип Space Apps открывает https://www.spaceappschallenge.org/ в новой
  вкладке. Сам SVG и центрирование сохранены; ссылка доступна с клавиатуры.
- В шапке один компактный список Қазақша / English / Русский. Видимая
  подпись и пункт «Язык системы» убраны; доступное название списка сохранено.
- При каждом открытии выбирается основной системный язык браузера
  (kk/en/ru с региональными вариантами), иначе — английский. Дополнительные
  языки предпочтений не подменяют неподдерживаемый основной язык.
  Старые значения localStorage игнорируются; ручной выбор действует
  в открытой странице и сохраняет звук/позицию. Перезагрузка снова
  использует системный язык или английский.
- **12 дополнительных браузерных сценариев пройдены**: kk/en/ru,
  неподдерживаемый язык, миграция старых настроек, смена языка системы,
  ручной выбор, клавиатура, 6 ширин экрана, новая вкладка логотипа и
  сохранение воспроизведения. Результат: `header-0.6.0-browser.xml`.

## Восстановленный раздел научных работ

После «Как это работает» добавлена отдельная вкладка «Научные работы»
(kk/en/ru). Из истории до упрощения v0.4.2 восстановлены две публикации,
краткий полевой контекст, годы наблюдений и ссылки на оригиналы:

- T. M. Bragina, *Soil macrofauna (invertebrates) of Kazakhstanian Stipa
  lessingiana dry steppe*, Hacquetia 15(2), 105–112 (2016), наблюдения
  Наурзума 2010 года. [DOI](https://doi.org/10.1515/hacq-2016-0017),
  [страница журнала](https://ojs.zrc-sazu.si/hacquetia/article/view/4645).
- G. J. Sultangazina, A. N. Kuprijanov, *Floral composition of the botanical
  natural monument “Kamenny lake tract” (Kostanay region)*, ENU Bioscience
  145(4), 63–70 (2023), исследования 2019–2022 годов.
  [DOI](https://doi.org/10.32523/2616-7034-2023-145-4-63-70),
  [страница журнала](https://bulbio.enu.kz/index.php/main/article/view/324).

Названия, библиографические сведения и даты сверены со страницами журналов.
Публикации доступны при выборе обеих областей, но явно относятся к Костанаю.
Для Акмолы показано отдельное пояснение; отсутствие локального списка флоры
Аккума также сохранено. Полевые сведения не выдаются за наблюдения NASA.
Смена вкладки и языка, а также открытие DOI в новой вкладке сохраняют
воспроизведение, паузу, источник аудио и масштаб карты.

Целевой повторный прогон: **24 браузерных сценария и 3 проверки переводов
пройдены** (`research-0.6.0-browser.xml`, `research-0.6.0-locales.xml`).
Проверяются обе области, ru/kk/en, шесть ширин 320–1440 px, клавиатура,
DOI в новой вкладке, сохранение звука и паузы. Измерения компоновки ожидают
асинхронного изменения ширины iframe Streamlit, чтобы исключить замеры
предыдущего размера окна. Полный архивный набор повторно не запускался.

## Проверки кандидата

Финальный кандидат с номером **0.6.0**:

- **37 целевых браузерных сценариев пройдено**, 399.411 с,
  включая настоящие данные обеих областей и обоих источников.
- `pip check`: No broken requirements found; синтаксис четырёх JS-файлов
  и всех Python-модулей, а также `git diff --check` проверены.
- [Машиночитаемая сводка](media/v0.6.0/validation.json).

В итоговом прогоне исправлен отступ в опциональном тесте реального кэша;
он и остальные тесты успешно собраны и выполнены. Исходные данные
опубликованных `data/real-test` не изменены.

```bash
.venv/bin/python -m pip check
.venv/bin/python -m pytest -q --junitxml=test-results/release-0.6.0-unit.xml

STEPPE_REAL_CACHE=/path/to/prepared/steppe-jukebox \
STEPPE_BROWSER_EXECUTABLE=/snap/chromium/current/usr/lib/chromium-browser/chrome \
.venv/bin/python -m pytest -m browser \
  tests/test_route_panel.py tests/test_map_view.py tests/test_preset_markers.py \
  tests/test_route_browser.py tests/test_live_browser.py tests/test_minimal_instrument.py \
  tests/test_ui_navigation.py tests/test_route_real_browser.py -q \
  --junitxml=test-results/release-0.6.0-browser.xml
```

`STEPPE_REAL_CACHE` указывает на подготовленный каталог с `nasa-gibs`
и `nasa-eic`. Реальный тест копирует его в изолированный tmp-каталог и
запрещает внешние HTTP-запросы. Это проверка настоящих наблюдений и кэша,
а не повторный замер холодного скачивания NASA. Проверяются обе области,
GIBS/10.06.2026 и EIC/20.04.2026, маршруты через ячейки, ранее блокировавшиеся
отменённым прототипом, а также нулевой PCM **KST-006 / 2,5–3,0 с**.

## Границы приёмки

- Полный архивный набор браузерных тестов не объявляется зелёным:
  восемь прежних сбоев воспроизведены на неизменённом `58eb330` ещё до
  этой версии. Семь относятся к старым ожиданиям видимости элементов
  после Minimal Instrument; один — к краевой подписи оси в архивной
  одноточечной фикстуре. Подробности: [историческая приёмка](ISSUE_17_WATER_HISTORY.md).
- Настоящий экранный диктор, физическое мобильное устройство, школьная
  приёмка, подробное сравнение воспринимаемых сезонных различий и
  отправка конкурсной заявки не подтверждены этой версией.
- Годовая водная маска и научная QA не входят в принятый MVP.
  Файлы скачанных тайлов остаются вне Git/релизных ресурсов.
- Исследовательский документ о Godot остаётся вне этого выпуска.

## Задачи

- #17 — текущий маршрутный MVP принят пользователем; закрывается после
  слияния с main.
- #14 — загрузчики, источники, точная дата, сетка и проверенный кэш
  реализованы; ручной координатный прототип заменён принятым #17.
  Закрывается актуальный объём, исторические непроведённые замеры
  не помечаются пройденными.
- #1–#7 и #11 сохраняют только фактически оставшиеся пункты: отдельные
  проверки исходных кадров/прослушивания/доступности, новые сезоны,
  школьную проверку и конкурсную подачу. Успешная общая пользовательская
  приёмка не подменяет эти специальные результаты.

## Запуск

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Открыть http://localhost:8501. Выбрать область, источник и дату, нажать
«Загрузить маршрут», затем «Запустить». Для изменения точек раскрыть
панель под загрузкой и включить «Выбрать на карте».

Подробный отчёт по пользовательскому маршруту:
[ISSUE_17_LOCAL.md](ISSUE_17_LOCAL.md).
