# Выпуск v0.2.0

Релиз Костанайского сценария от 2026-11-14. Основа — костанайская часть #11, дополнение к данным #1, звуку #2 и интерфейсу #3. Прежний `v0.1.0-preview.1` сохранён. Акмолинская область по решению пользователя отложена и в v0.2.0 не входит; #11 остаётся открытой для следующего этапа.

## Что входит

- Режим одной даты для всего маршрута: фиксированные весенний и летний срезы.
- Новый режим путешествия: 48 точек, 2026-04-15 … 2026-11-13; ближайшая к Наурзуму точка KST-018 имеет дату 2026-07-01.
- Одна шкала, шаг 0,5 с, 120 BPM и одна громкость синтеза для всех дорожек. Путешествие и фиксированный NOAA‑20 срез длятся по 24 с.
- Общий аудиочас для карты, строки таблицы, даты, ориентира и текущей позиции. Пауза/продолжение, повтор и остановка при смене режима.
- kk/en/ru для новых подписей, статусов и ошибок, клавиатурное управление; географические оси и координаты из #10.
- Реальные CSV из #1 и #11 с отдельными сведениями о происхождении. Их классы не пересчитывались и не интерполировались.
- Экспорт `journey.wav` и `journey_timing.csv` с датами и теми же границами интервалов, что в интерфейсе.

README обновлён из-за изменения набора по умолчанию и добавления режима; MANIFESTO и LICENSE не изменены. Отдельный документ про Godot не относится к этому выпуску.

## Локальная проверка

Python 3.11+, зависимости из `requirements.txt` / `requirements-dev.txt`:

```bash
python -m streamlit run app.py
python -m pytest -q
python -m playwright install chromium
python -m pytest -m browser -q
python -m steppe_jukebox.export --data-dir data/real-test/noaa20-kostanay --output-dir artifacts/real-test/noaa20-kostanay
```

По умолчанию открывается NOAA‑20. Для путешествия выбрать «Режим → Путешествие во времени». Начальный режим фиксированной даты позволяет сразу сравнить срез 2026-04-15 с путешествием на том же маршруте. При возврате к фиксированному режиму ранее выбранный сезон сохраняется.

Общий прогон: **118 passed** — 80 проверок Python и 38 браузерных. Проверки охватывают точный порядок ID/дат/классов, календарную формулу всех 48 дат, PCM и тишину, первую/среднюю/последнюю дату, полный 24-секундный проход всех шагов, клавиатуру, переключение режима, отмену незавершённого запуска, пропуск в тестовой копии и прежние сценарии сезонов/языков/осей. `pip check` и проверка синтаксиса JavaScript также прошли.

Чистый запуск по README дополнительно проверен: новая изолированная `.venv` на Python 3.12.3, установка только `requirements.txt`, запуск без `STEPPE_DATA_DIR`. Против этого сервера прошли ещё два контрольных браузерных сценария: даты/клавиатура/пауза/повтор путешествия и переключение между путешествием и фиксированным срезом. Зависимости не содержат конфликтов по `pip check`. Чистое окружение проверялось на той же машине; проверка экранным диктором в него не входила.

## Ограничения интерпретации

Источник путешествия — [NASA GIBS NOAA‑20/VIIRS, rolling 8-day NDVI](https://gibs.earthdata.nasa.gov/layer-metadata/v1.0/VIIRS_NOAA20_NDVI_8Day.json), классы предоставлены в #11 по отображаемой легенде. Даты не представляют независимые суточные измерения; CSV не содержит численного NDVI. В путешествии одновременно меняются место и дата: оно не устанавливает временной тренд растительности.

Сопоставление таблиц с 2026-04-15: из 47 пар с данными 34 класса различаются, 16 выше и 18 ниже; ещё 13 совпадают. Это техническое описание последовательностей, не результат человеческого прослушивания.
